# Photonic Railway

An open technical study of an uncrewed cislunar cargo railway from LEO through EML-1 and EML-2 and LLO to the lunar surface. The line is built from nested toroidal-shell nodes, linked by laser for power, timing, and navigation, and uses a common 4.9 m tunnel standard. Surface work uses a 600 kg-class lander and specialized droids.

This is a paper study only. No hardware has been built or tested. The current revision is Rev 2.23.

Author: Mathew Pennington, Sevierville, TN

## Calculated estimates (Rev 2.23)

These figures are calculated estimates, not tested values. Proposed values are kept separate from calculated ones.

- Programme cost: mid $4,913.4M, low $3,327.5M, high $10,572.8M
- BOM flight mass: 80,760.8 kg
- 13 landings and 20 launches
- Night power: a 40 kWh regenerative fuel cell against a 37.463 kWh worst-case need, using round-trip efficiency 0.313

## Open items

- O-145: the choice between 12 and 13 landings is undecided.
- O-147: the survival-tier night-power margin is -31.65% before the fuel cell lands.
- O-148: launch cost is understated by about $371M and is not yet in the totals.
- O-150: compatibility with the International Docking System Standard (IDSS) has not been checked.
